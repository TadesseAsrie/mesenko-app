#  Mesenko – Ethiopian Traditional Musical Instrument Simulator

A modern, interactive web application that simulates the **Mesenko**, one of Ethiopia's most iconic traditional musical instruments. Built entirely with **HTML5**, **CSS3**, and **Vanilla JavaScript**, the application combines authentic Ethiopian-inspired design with modern web technologies to provide an engaging musical and educational experience.

---

##  Overview

The Mesenko is a traditional one-string bowed instrument widely used in Ethiopian folk music. This project recreates the instrument digitally, allowing users to play notes using the keyboard, mouse, or touch controls while learning about its cultural importance.

The application features smooth animations, realistic sound effects using the Web Audio API, responsive layouts, and multiple interactive tools for learning and entertainment.
